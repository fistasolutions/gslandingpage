# World-Class Landing Page Creation Prompt

## Project Overview
Create a premium, modern SaaS landing page for "Rexona" - a CRM and financial management platform. The design should be visually stunning, conversion-optimized, and fully responsive.

## Design System

### Color Palette
- **Primary Dark Green**: #1a4d3a (main backgrounds, buttons)
- **Light Green Accent**: #4ade80 / #22c55e (CTAs, highlights, badges)
- **White**: #ffffff (text on dark, card backgrounds)
- **Dark Text**: #1f2937 (headings, body text on light backgrounds)
- **Light Text**: #f9fafb (text on dark backgrounds)
- **Gray Scale**: Various shades for subtle elements, borders, and secondary text

### Typography
- **Headings**: Bold, large, impactful (2.5rem - 4rem for hero)
- **Body Text**: Clean, readable (1rem - 1.125rem)
- **Small Text**: 0.875rem for badges, labels, captions
- **Font Family**: Modern sans-serif (Inter, Poppins, or system default)

### Spacing & Layout
- **Section Padding**: 80px - 120px vertical, 20px - 40px horizontal
- **Container Max Width**: 1280px centered
- **Grid Gaps**: 24px - 32px between elements
- **Border Radius**: 8px - 16px for cards, 24px - 32px for buttons

## Interactive Elements
- Smooth scroll behavior
- Hover effects on buttons (scale, color transitions)
- Accordion functionality for FAQ
- Testimonial carousel navigation
- Sticky navigation header
- Smooth animations on scroll (fade-in, slide-up)

## Responsive Design
- **Mobile**: Single column, stacked elements, adjusted font sizes
- **Tablet**: 2-column layouts where appropriate
- **Desktop**: Full multi-column layouts, optimal spacing

## Technical Requirements
- Next.js 16 with TypeScript
- Tailwind CSS v4 for styling
- React components with proper TypeScript types
- Semantic HTML5
- Accessible (ARIA labels, keyboard navigation)
- Performance optimized (lazy loading, image optimization)

## Implementation Notes
- Use CSS Grid and Flexbox for layouts
- Create reusable components (Button, Card, Section, etc.)
- Use Tailwind utility classes extensively
- Add subtle shadows and gradients for depth
- Ensure proper contrast ratios for accessibility
- Optimize images and use Next.js Image component
